# Interviews

Company-specific interview experiences and preparation notes.

## Purpose

Use this folder to track real interview experiences, round-by-round details, and lessons learned.

## Suggested Structure

Organize by year, then company.

```text
interviews/
├── 2026/
│   ├── company-a/
│   │   ├── overview.md
│   │   ├── round-1-dsa.md
│   │   └── round-2-system-design.md
│   └── company-b/
└── 2027/
    └── ...
```

## What to Capture

For each company/round, include:

- Role and level
- Interview date
- Round type (DSA / LLD / HLD / Behavioral)
- Questions asked
- Your solution summary
- Follow-up questions and discussion points
- Outcome
- Improvements for next time

## Reflection Template

- **What went well**
- **What I struggled with**
- **What to revise next**
- **Action items with deadlines**

## Goal

Build a reusable, high-signal interview history to improve performance over time.
