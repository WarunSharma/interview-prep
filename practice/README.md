# Practice

Problems and implementations practiced during a specific year.

## Structure

Use year-wise and topic-wise organization:

- `YYYY/`
  - `topic/`
    - `subtopic/`
      - `problem-file`

Current example:

- `2026/dsa/dynamic-programming/climbing-stairs.js`

## Per-Problem Notes (Recommended)

For each practice problem, capture:

- Problem statement/link
- Approach (brute force -> optimized)
- Time and space complexity
- Edge cases
- Key learnings

## Goal

Build consistency and maintain a clear history of progression over time.
