# Knowledge

Long-term concepts, notes, explanations, and references.

## Purpose

This folder is for foundational concepts you want to retain long-term and revise periodically.

## Scope

Typical areas include:

- DSA fundamentals
- System Design
- Low-Level Design (LLD)
- JavaScript / React / Node.js fundamentals
- Backend and AWS concepts

## Suggested Structure

Organize notes by topic and then by source/chapter/concept.

Example:

```text
knowledge/
├── dsa/
│   ├── arrays.md
│   ├── trees.md
│   └── dynamic-programming.md
└── system-design/
    └── alex-xu/
        ├── chapter-01.md
        └── chapter-02.md
```
