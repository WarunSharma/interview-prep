# Machine Coding

Hands-on coding problems and implementations.

## Purpose

Use this folder to practice end-to-end coding problems that evaluate design, implementation quality, and product thinking.

## Recommended Structure

For each problem, maintain:

- `problem-statement.md` (requirements, assumptions, constraints)
- Source code folder
- `README.md` for approach and setup

## What to Capture

- Functional requirements
- Non-functional requirements
- API/contracts and data models
- Trade-offs and design decisions
- Future improvements

## Evaluation Checklist

- Correctness
- Code readability
- Modularity
- Error handling
- Scalability and extensibility
