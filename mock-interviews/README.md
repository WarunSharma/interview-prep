# Mock Interviews

Practice interviews, questions, feedback, and improvements.

## Purpose

Track mock sessions and continuously improve interview performance through structured feedback.

## Session Template

For each session, capture:

- Date
- Interview type (DSA / System Design / LLD / Behavioral)
- Questions asked
- Your approach summary
- What went well
- What to improve
- Action items for next session

## Suggested Naming

`YYYY-MM-DD-topic.md`

Examples:

- `2026-09-19-dsa.md`
- `2026-09-25-system-design.md`

## Improvement Loop

1. Attempt under timed conditions
2. Review feedback
3. Re-solve weak areas
4. Re-attempt similar problems
